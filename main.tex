  \title{Boundedness Analysis for Smart Contracts}

  \author{
    Fausto Spoto\orcidlink{0000-0003-2973-0384}
  }
  \institute{
    Dipartimento di Informatica, Universit\`a di Verona, Italy\\
    \email{fausto.spoto@univr.it}
  }

  \maketitle

  \begin{abstract}
    The interaction between smart contracts and their users exposes
    the former to specific risks, such as the arbitrary increase
    of the size of some data container, that are consequently \emph{unbounded}.
    This, in turn, might translate into
    a security issue, that blocks the functionality of the smart contract or
    locks some money inside it. This paper describes the problem and
    proposes a sound static analysis based on abstract interpretation,
    that proves containers bounded and issues a warning otherwise.
    We apply the analysis on some examples smart contracts and provide
    a prototype implementation.
  \end{abstract}

\end{frontmatter}
